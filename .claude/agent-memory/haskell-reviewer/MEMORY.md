# Haskell Reviewer Memory

- [Transitive Hash(..)/AsType(..) re-export gotcha](reference_transitive_hash_reexport.md) — don't declare a constructor "out of scope" from export-list greps alone; data-family wildcards pull in constructors transitively
- [Never solo-run subproject builds during review](feedback_no_subproject_builds_solo.md) — even to self-verify a "won't compile" claim; ask for permission or defer to a builder/verifier agent instead
- [protobuf enum value scoping](reference_protobuf_enum_value_scoping.md) — enum VALUE symbols are scoped to the enum's enclosing scope, not the enum type; easy category to miss in a hand-rolled reflection/descriptor symbol index
- [Fetch reference implementations for spec-divergence questions](feedback_fetch_reference_implementations.md) — pull the actual reference source (gh api/WebFetch); different "reference" implementations can disagree with each other
- [Verify claimed fixes by diff, not commit message](feedback_verify_claimed_fixes_by_diff.md) — a multi-commit "fix" pass can genuinely fix some flagged items while silently dropping others (PR #6693); also: grep changed files for em-dashes every pass, authors reintroduce them
- [Verify function behaviour at an exact pinned SRP commit](reference_verify_srp_pinned_commit.md) — `gh api repos/.../commits/<sha>` to read a file/patch at an unreleased pin without cloning; sibling checkouts and agentix are usually stale for this. Disproved a PR's own changelog root-cause claim and a Copilot comment on cardano-cli PR #1423
- [Companion PR as cross-check](reference_companion_pr_cross_check.md) — use a sibling-repo consumer PR to confirm a missing import's true source module; indexed dependency checkouts can be stale in the "missing new fields" direction too, not just "newer than pinned"
- [cardano-cli UnitInterval pparam option convention](reference_cli_unitinterval_pparam_parser_convention.md) — safe idiom is bounds-check inside the ReadM (`readRationalUnitInterval`/bespoke `toXOrErr :: Rational -> Opt.ReadM X`); routing an unbounded `readRational` through `convertToLedger <error-throwing-conv>` crashes on bad input instead of a clean usage error. Caught on cardano-cli PR #1445
- [File newtype derives JSON from FilePath](reference_file_newtype_derived_json.md) — manual unFile/File wrap in aeson instances isn't proof of a tag mismatch; check the deriving clause before calling it an awkward shim
- [try's TypeApplication order](reference_try_typeapplication_order.md) — safe-exceptions' `try @m @e`, not `@e @m` — implicit forall scans constraints left-to-right first
- [Diff committed and uncommitted separately](feedback_diff_committed_and_uncommitted_separately.md) — reading the working-tree file can hide a REPLACE_ME/wrong-path bug still sitting in the committed state, fixed only locally. Caught on cardano-cli PR #1452
- [CHaP no-SRP pinned version check](reference_chap_no_srp_pinned_version_check.md) — no source-repository-package override means the real dependency is a released CHaP tarball, not "unreleased master" as claimed; download and read it. Disproved cardano-cli PR #1452's own framing and caught a genuine `unKESPeriod` type error
- [other-modules named re-export gotcha](reference_other_modules_named_reexport.md) — a function in cabal `other-modules` can still be public if an `exposed-modules` sibling names it in its own export list; check every exposed file, not just the definer. Caught on cardano-api PR #1359
- [eraMaxLanguage vs mkPlutusScript](reference_era_max_language_vs_mkplutusscript.md) — ledger's `eraMaxLanguage` is not authoritative for what `mkPlutusScript` accepts per era; read the actual instance body. cardano-ledger-dijkstra-0.2.0.1 claims V3 max but accepts V4
- [NumericUnderscores pragma check](reference_numericunderscores_pragma_check.md) — cardano-api's common stanzas don't enable it; underscored literals need a per-file pragma. Caught a real compile error on cardano-api PR #1359
- [RIO MonadFail on the production path](reference_rio_monadfail_production_path.md) — RIO's MonadFail bottoms out in IO's raw fail; trace a MonadFail constraint to where it's instantiated (CLI vs Hedgehog), not just where it's used. Caught on cardano-node PR #6710
- [cardano-testnet proc builder families](reference_cardano_testnet_proc_builder_families.md) — RIO-based procFlex (production) vs MonadTest-based procSubmitApi/procChairman (test-only) are not interchangeable; a new unused proc* may be in the wrong family. Caught on cardano-node PR #6710
- [Check insertWith/unionWith argument order](feedback_check_insertWith_arg_order.md) — a "copy if missing" merge helper must branch on the OLD/existing map having the key, not the NEW/template one; a wrong-side check silently overwrites. Caught on cardano-node PR #6710's TraceOptions merge logic, untested path
- [trace-dispatcher root-namespace override](reference_trace_dispatcher_root_namespace_override.md) — cardano-node's TraceOptions."" fully replaces defaultCardanoConfig's root namespace rather than merging per-field; a config-rewrite that sets backends there silently drops the node's default Stdout MachineFormat. Caught on cardano-node PR #6710

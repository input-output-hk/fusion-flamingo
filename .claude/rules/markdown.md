# Markdown style
- One sentence per line. Never put multiple sentences on the same line.
  Keeps diffs clean - a change to one sentence does not touch adjacent sentences.
- Never use em dashes (U+2014) or double dashes (`--`).
  Always use a single hyphen-minus (`-`) surrounded by spaces instead.
  Use commas, colons, semicolons, or parentheses as alternatives when appropriate.
- Always use British English.
  E.g. "behaviour" not "behavior", "standardise" not "standardize", "favour" not "favor", "serialisation" not "serialization".
